Descritor D097_M: Utilizar propriedades de progressões geométricas na resolução de problemas

Resumo Teórico: Progressão Geométrica (P.G.)

Uma Progressão Geométrica (P.G.) é uma sequência numérica em que cada termo, a partir do segundo, é igual ao anterior multiplicado por uma constante chamada razão (q).

Termo Geral: an = a1 · qn-1
Soma dos n primeiros termos: Sn = a1 · (qn - 1) / (q - 1)   (para q ≠ 1)

  • a1: Primeiro termo da sequência.
  • q: Razão da P.G. (calculada dividindo qualquer termo pelo anterior: q = a2 / a1).
  • n: Número de termos ou posição do termo desejado.
  • an: n-ésimo termo (termo geral).
  • Sn: Soma dos n primeiros termos.

📌 EXEMPLO RESOLVIDO PASSO A PASSO (Para Relembrar)

Enunciado Exemplo: Uma população de bactérias começa com 50 indivíduos (a1 = 50) e dobra a cada hora (q = 2). Quantas bactérias haverá após 5 horas (a5)?

Como resolver passo a passo:

1. Anotar os dados do exercício: • Primeiro termo (a₁) = 50 • Razão (q) = 2 (dobra a cada hora) • Posição desejada (n) = 5 (5ª hora) 2. Escrever a fórmula do termo geral da P.G.: aₙ = a₁ · qⁿ⁻¹ 3. Substituir os valores na fórmula: a₅ = 50 · 2⁵⁻¹ a₅ = 50 · 2⁴ 4. Calcular a potência primeiro (2⁴ = 16): a₅ = 50 · 16 5. Multiplicar os valores: a₅ = 800 bactérias ✅

💡 Dica: Lembre-se de calcular primeiro as potências antes de efetuar as multiplicações!

Lembrete: Progressão Geométrica (P.G.)

Termo Geral: an = a1 · qn-1 | Soma dos Termos: Sn = a1 · (qn - 1) / (q - 1)

Exemplo Rápido: Se a₁ = 50 e q = 2: a₅ = 50 · 2⁴ = 50 · 16 = 800
